# 📈 Stock Trade Capstone Project

![Stock Trading](https://media.giphy.com/media/l0Exk8EUzSLsrErEQ/giphy.gif)

## About the Project
The **Stock Trade Capstone Project** is a full-stack Robinhood-style trading app where users can:

✅ **View a personalized dashboard** with stock holdings 📊  
✅ **Deposit & withdraw funds** from a virtual bank account 💰  
✅ **Simulate buying & selling stocks** with real-time updates 📈  
✅ **Track portfolio performance** with visual insights 📉  

---

## Tech Stack

### **Frontend**  
- **Angular (planned but later switched to Thymeleaf for faster UI development)**  
- **Bootstrap for styling**

### **Backend**  
- ☕ **Spring Boot** (Java)
- 🗄 **MySQL Database** for persistent storage

### **Version Control**
- 🛠 **Git & GitHub** for collaboration & tracking changes

## 📂 Project Setup

1️⃣ Clone the repository:
```bash
  git clone https://github.com/yourgithub/stock-trade.git
```

2️⃣ Navigate to the backend folder & start Spring Boot:
```bash
  cd backend
  mvn spring-boot:run
```

3️⃣ Navigate to the frontend folder & start the UI:
```bash
  cd frontend
  npm install
  npm start
```
